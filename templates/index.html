Key Security Filesystem Paths
/etc - System-wide configuration

Contains /etc/passwd (accounts), /etc/shadow (hashes), /etc/sudoers, and network service daemons.

/var/log - Audit & Intrusion Logs

Contains auth.log, syslog, and web server logs. Crucial for incident response and tracking recon probes.

/proc & /sys - Kernel Virtual Interfaces

Live process memory tables. Inspecting /proc/[PID]/cmdline reveals full arguments of running commands.

/tmp & /var/tmp - Staging Areas

World-writable directories with Sticky bit (1777). Commonly leveraged in penetration testing to stage scripts.

Discretionary Access Controls (DAC)

Linux file permissions are represented as 3 triads: Owner (User), Group, and Others, each with Read (4), Write (2), and Execute (1) weights.

Octal Symbolic Security Meaning
755 rwxr-xr-x Standard for system binaries and directories. Owner full, others read/traverse.
644 rw-r--r-- Standard configuration files (e.g. /etc/passwd). Readable by all, writable by root.
600 rw------- Sensitive files (SSH private keys, /etc/shadow). Owner read/write only.
4755 rwsr-xr-x SUID Bit Runs with file owner permissions (e.g. /usr/bin/passwd).
777 rwxrwxrwx Critical Risk World-writable. Any local account can overwrite code.

Port 8080 probe details loading...

Standard Lab Setup Protocol:

  1. Proxy Configuration: Open Burp -> Settings -> Tools -> Proxy. Confirm listener on 127.0.0.1:8080 is running.
  2. CA Certificate Import: Browse to http://burp/ while proxying, click CA Certificate, and import into Firefox/Chrome Trusted Root Authorities.
  3. Target Scope: Set Target -> Scope to http://127.0.0.1:5000/ to confine testing strictly to this lab.
  4. Reconnaissance Mapping: Navigate the application. Burp's Proxy -> HTTP History records parameters, headers, cookies, and hidden endpoints.
  5. Repeater Probing: Send interesting requests to Repeater (Ctrl+R) to inspect response variance against modified payloads.
